# Naveen's Portfolio — Two-Track Design

A Next.js portfolio with a split-personality design:

- **/** — Split-screen landing where visitors choose their path
- **/professional** — AI-Driven Application Designer (enterprise, architecture, Salesforce)
- **/creator** — AI Cinematic Creator (mythology, storytelling, content, B2B studio)

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

```bash
# Push to GitHub first, then:
npx vercel
```

Or connect your GitHub repo at [vercel.com](https://vercel.com).

## Customization

- Update social links in both track pages
- Replace placeholder email addresses
- Add project screenshots/thumbnails
- Update experience details in professional track
- Add your resume PDF to `/public`
